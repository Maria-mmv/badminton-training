# Badminton Training — локальная PWA

## Что реализовано
- Библиотека упражнений: поиск, фильтры по основной теме и уровню.
- Создание и редактирование карточек.
- Отдельные поля для основной темы, видов ударов и дополнительных тегов.
- Загрузка главного изображения и дополнительных изображений в галерею.
- Несколько видеоссылок с названием и комментарием.
- Общие заметки, личная оценка сложности и заметки после тренировок.
- Конструктор: добавление упражнений, изменение длительности и порядка.
- Сохранение планов и открытие их копии для редактирования.
- Экспорт и импорт полной резервной копии JSON.
- Локальная база IndexedDB и базовая поддержка установки как PWA.

## Запуск на компьютере
PWA и Service Worker требуют localhost или HTTPS. В каталоге проекта выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Запуск на Android и компьютере
Для установки на Android проект нужно разместить на HTTPS-хостинге. Откройте ссылку в Chrome и выберите «Установить приложение» / «Добавить на главный экран». На компьютере Chrome/Edge также предложит установку.

## Хранение и перенос
Данные и фотографии сохраняются в IndexedDB конкретного браузера и устройства. Между телефоном и компьютером автоматической синхронизации пока нет. Используйте раздел «Данные» → «Экспортировать JSON» на одном устройстве, затем «Импортировать JSON» на другом.

## Важные ограничения первой версии
- Облачная синхронизация пока не подключена.
- Изображения уменьшаются до максимальной стороны 1400 px и сохраняются в JPEG для экономии места.
- Видеофайлы не загружаются: сохраняются ссылки на внешние видео.
- Перед очисткой данных браузера обязательно экспортируйте резервную копию.

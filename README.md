# Badminton Training — локальная PWA

## Что реализовано
- Библиотека упражнений: поиск, фильтры по основной теме и уровню.
- Создание и редактирование карточек.
- Отдельные поля для основной темы, видов ударов и дополнительных тегов.
- Загрузка главного изображения и дополнительных изображений в галерею.
- Несколько видеоссылок с названием и комментарием.
- Общие заметки, личная оценка сложности и заметки после тренировок.
- Конструктор: добавление упражнений, изменение длительности и порядка.
- Сохранение планов и открытие их копии для редактирования.
- Экспорт и импорт полной резервной копии JSON.
- Локальная база IndexedDB и базовая поддержка установки как PWA.

## Запуск на компьютере
PWA и Service Worker требуют localhost или HTTPS. В каталоге проекта выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Запуск на Android и компьютере
Для установки на Android проект нужно разместить на HTTPS-хостинге. Откройте ссылку в Chrome и выберите «Установить приложение» / «Добавить на главный экран». На компьютере Chrome/Edge также предложит установку.

## Хранение и перенос
Данные и фотографии сохраняются в IndexedDB конкретного браузера и устройства. Между телефоном и компьютером автоматической синхронизации пока нет. Используйте раздел «Данные» → «Экспортировать JSON» на одном устройстве, затем «Импортировать JSON» на другом.

## Важные ограничения первой версии
- Облачная синхронизация пока не подключена.
- Изображения уменьшаются до максимальной стороны 1400 px и сохраняются в JPEG для экономии места.
- Видеофайлы не загружаются: сохраняются ссылки на внешние видео.
- Перед очисткой данных браузера обязательно экспортируйте резервную копию.


## Синхронизация через Google Drive

В приложении добавлена синхронизация через Google Apps Script и Google Drive.

1. В Google Apps Script должен быть создан проект с файлами `Code.gs` и `Bridge.html`, запущена функция `setupSync()` и опубликовано веб-приложение.
2. В разделе **Данные → Синхронизация через Google Drive** на каждом устройстве вставьте один и тот же `SYNC_TOKEN`, полученный в журнале выполнения `setupSync()`, и нажмите **Сохранить ключ на этом устройстве**.
3. При первом подключении приложение предложит загрузить данные из облака или отправить локальные, если обе копии уже содержат записи.
4. После успешного подключения синхронизация запускается автоматически после локального изменения с небольшой задержкой, при открытии приложения и по кнопке **Синхронизировать сейчас**.
5. На втором устройстве нужно отдельно сохранить тот же ключ. Сам ключ хранится в localStorage этого браузера и не включён в файлы GitHub.

Фотографии хранятся как JPEG data URL в данных упражнений и передаются вместе с `data.json`. Видео по-прежнему хранятся только как внешние URL. Для первой версии действует ограничение около 7,5 МБ на общую JSON-запись; при большом количестве фотографий их следует уменьшить.

При обнаружении изменений на обоих устройствах приложение не объединяет карточки автоматически: оно предлагает выбрать локальную или облачную версию, чтобы избежать незаметной перезаписи.

**Важно:** локальные данные в IndexedDB и экспорт JSON не удаляются при подключении облака. При первой синхронизации внимательно выбирайте, какую библиотеку оставить.

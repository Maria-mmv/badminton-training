Обновление: категории в разделе «Мои планы»

В архиве находятся полные файлы приложения:
- app.js.txt — основной JavaScript;
- index.html — разметка приложения;
- styles.css — стили;
- sw.js.txt — Service Worker.

Что добавлено:
1. В «Мои планы» появились фильтры: Все, Бадминтон, Растяжка, Физическая подготовка.
2. При создании нового плана можно выбрать тему в конструкторе тренировки.
3. У каждого сохранённого плана есть выпадающий список темы — категорию можно изменить.
4. При создании копии плана или плана из записи журнала его категория переносится.
5. Для старых планов без категории приложение предлагает категорию по содержимому. Её можно проверить и изменить в списке планов.

Установка:
1. Сделайте резервную копию данных в приложении через «Данные» → «Экспортировать JSON».
2. Замените в корне GitHub-репозитория файлы из архива.
3. Переименуйте app.js.txt в app.js и sw.js.txt в sw.js.
4. Сделайте Commit changes и дождитесь обновления GitHub Pages.
5. Обновите приложение.

База IndexedDB и схема облачной синхронизации не меняются. Google Apps Script редактировать не нужно.
